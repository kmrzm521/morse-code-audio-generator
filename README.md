# 摩斯电码生成器第六版（离线版）

这是从旧版重新设计的精简版视窗小程序。软件运行时完全不联网，默认生成压缩音频，也支持波形音频，并为每个音频生成同名同步字幕。

## 主要功能

- 随机字母、数字、混合内容、标点、通联符号和无线电简语
- 普通数字编码与缩短数字编码
- 中国省级模拟呼号
- 覆盖 340 个现行业余无线电实体的全球标准模拟呼号
- 自定义文本
- 每分钟 5 至 60 字、300 至 1200 赫兹
- 可选间隔降速
- 压缩音频、波形音频和同步字幕
- 分块生成长音频，自动防止覆盖已有文件
- 本地保存上次设置
- 普通用户每次最多五分钟，单机永久会员不设软件时长上限

全球规则来自开放许可的 2020 年 2 月快照。模拟呼号只用于听抄训练，不代表主管机构已经实际签发，也不能据此用于发射。

## 使用方法

1. 选择内容类型。
2. 设置每组字符、生成时长、字符速度和音调。
3. 如需放慢字符间隔，勾选“间隔降速”并设置更低的间隔速度。
4. 选择压缩音频或波形音频，并指定输出目录。
5. 点击“生成音频和同步字幕”。

自定义文本会完整生成，不按目标时长裁剪。随机内容按完整字符组追加，最终时长可能比目标多一个完整组。

## 永久会员离线激活

普通用户选择超过五分钟的时长时，主程序会提示永久会员限制。

1. 用户在“会员激活”窗口复制机器码。
2. 软件所有者打开“会员激活码生成工具”，粘贴机器码并生成永久激活码。
3. 用户把激活码粘贴回主程序并完成激活。

整个过程不需要服务器。激活码绑定一台电脑；主要硬件或系统设备标识变化后，需要重新签发。

所有者私钥文件名为 `owner-private-key.txt`。它只保存在本地所有者目录，不会提交到代码仓库，也不会进入公开主程序。私钥一旦丢失，现有主程序对应的新激活码将无法继续签发，因此必须妥善备份。

## 音频与时序

文件扩展名 `.mp3` 表示压缩音频，`.wav` 表示波形音频，`.lrc` 表示同步字幕。扩展名属于文件格式技术标识。

点划与间隔遵循国际电联相关建议：

- 点：1 单位
- 划：3 单位
- 同一字符内：1 单位
- 字符之间：3 单位
- 单词或字符组之间：7 单位

点长按每分钟标准字数计算。采样率为 44100、16 位、单声道，默认音调为 700 赫兹；这些是程序工程参数，不是国际电联强制参数。

参考：[国际电联摩斯电码时序建议](https://www.itu.int/rec/R-REC-M.1677-1-200910-I/)、[工业和信息化部业余无线电台呼号编制要求](https://wap.miit.gov.cn/cms_files/filemanager/1226211233/attach/20238/e3a97cec523441028cc51de62886101c.pdf)。

## 源码运行和测试

需要 64 位 Python 3.13。运行时不需要网络；依赖安装和首次构建需要提前准备软件包。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe main.py
```

## 打包

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

公开主程序位于 `dist\摩斯电码生成器.exe`。所有者工具和私钥位于 `owner-release`，该目录不得发送给普通用户。
