# 全中文、全球模拟呼号与离线永久会员设计

## 目标

在现有离线摩斯电码生成器上完成三项改进：用户可见内容全部中文化；将八国模拟呼号扩展为覆盖全球业余无线电实体的标准模拟呼号；增加普通用户五分钟限制和绑定单机的离线永久会员。

## 产品边界

- 软件运行时完全不联网。
- 不下载、不打包、不宣称拥有全球真实个人呼号数据库。
- 全球呼号仅按国际前缀和地区常见格式模拟生成，不代表主管部门已经实际签发。
- 呼号、文件扩展名和音频文件内部格式标识属于技术数据，不视为英文界面文案。
- 内部程序字段可以保留英文，所有窗口、按钮、提示、报错、文件说明和字幕元数据必须使用中文。

## 全中文界面

界面将“字符速度”“有效速度”“音调频率”“压缩音频”“波形音频”“普通数字”“缩短数字”等作为显示名称，内部仍映射到现有设置值。删除界面和用户错误信息中的 `WPM`、`Hz`、`Farnsworth`、`long`、`short`、`MP3`、`WAV`、`LRC`、`Morse Code Practice` 等英文文案。

输出文件名改用中文单位和中文类别，例如“字母_每分钟20字_700赫兹_时间”。同步字幕元数据使用中文字段和值。文件扩展名仍由操作系统按实际格式显示。

## 全球标准模拟呼号

采用内置、版本化的全球业余无线电实体规则表。每条规则至少包含中文实体名称、可选前缀、前缀后的数字规则、后缀长度以及必要的例外说明。界面国家选择器按中文名称排序，并提供“随机全球地区”。

规则基础为国际电联国际呼号序列分配和业余无线电国家文件。国际电联分配只能证明前缀归属，不能证明某个完整呼号真实存在。因此界面和字幕统一标注“标准模拟呼号”。

中国呼号继续使用现有省级分区和台站类别规则。全球规则生成器只负责格式合理性，不提供真实持证状态查询。本地真实呼号导入功能从本次范围中移除，避免产品同时出现两套含义不同的呼号来源。

规则数据独立于生成代码，便于以后人工更新。应用关于区域显示规则版本和依据说明，但不提供联网更新。

## 时长和会员权限

普通用户每次生成最长五分钟。界面时长超过五分钟时，在开始生成前提示需要永久会员，不创建任何输出文件。

永久会员不设置软件时长上限，但仍受磁盘空间、可用内存和音频编码能力限制。界面明确说明这一点，防止把物理限制误解为会员限制。时长输入改为仅校验不少于五秒的正整数，并采用分块生成方案控制内存占用。

## 离线永久激活

主程序生成不可逆的机器码摘要，并提供复制按钮。机器码由稳定的 Windows 设备标识计算，不包含姓名、邮箱或原始硬件信息。

单独提供“会员激活码生成工具”。工具使用爱德华曲线数字签名算法，输入机器码后生成永久激活码。主程序只内置验证公钥，验证激活码签名及机器码是否匹配。生产私钥作为独立文件仅由软件所有者保存，不得进入主程序、公开仓库或公开发行压缩包；激活工具从同目录的私钥文件读取。

主程序保存激活码并在启动及生成前校验。配置文件被复制到另一台电脑、机器码被修改或激活码内容被篡改时，会员状态无效。更换主要硬件导致机器码变化时，由软件所有者重新签发。

## 界面流程

主窗口增加中文会员状态和“会员激活”入口。激活窗口显示机器码、复制按钮、激活码输入框和激活结果。普通用户选择超过五分钟后直接引导到激活窗口；会员正常进入生成流程。

全球呼号区域显示实体选择器和固定提示：“按国际前缀及地区格式模拟生成，不代表真实签发”。不再使用“全球真实呼号”或类似表述。

## 错误处理

- 全球规则缺失或损坏：提示“全球呼号规则数据不可用”，不回退到虚构规则。
- 激活码错误：区分“格式错误”“签名无效”“不适用于本机”，不泄露校验细节。
- 普通用户超时：提示五分钟限制，并允许打开激活窗口。
- 超长生成资源不足：保留已完成文件的安全清理规则，使用中文错误信息说明原因。

## 验证标准

- 自动扫描全部用户可见文案，不出现已知英文界面词。
- 每个内置业余无线电实体至少能生成一个符合其规则的模拟呼号。
- 固定随机种子的呼号生成结果可重复，未知实体必须报错。
- 未激活状态允许五分钟、拒绝超过五分钟；有效本机激活码解除该产品限制。
- 篡改激活码、复制到另一机器以及损坏授权文件均无法获得会员权限。
- 主程序发行包不包含私钥；激活工具单独构建和保存。
- 完整测试、主程序打包测试和激活工具打包测试全部通过。
