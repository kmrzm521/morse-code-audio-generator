# 离线摩斯电码生成器设计

## 目标

用简洁、可维护的 Python 3.13 源码重建摩斯电码生成器。程序在 Windows 上使用图形界面，完全离线运行，默认输出 MP3，同时支持 WAV 和同步 LRC。

## 范围

保留以下内容类型：

- 随机字母
- 数字长码和数字短码
- 字母数字混合
- 标点符号
- 通联符号
- Q 简语
- 中国呼号
- 全球呼号
- 用户输入的自定义文本

删除以下功能：

- MP4 视频生成
- Edge TTS 和 NATO 语音朗读
- 问题反馈邮件
- 所有联网功能

## 用户界面

界面使用 Tkinter，中文显示，单窗口布局。用户可以设置：

- 内容类型
- 每组字符数
- 生成时长
- 摩斯速度，默认 15 WPM
- 音调频率，默认 700 Hz，允许 300 至 1200 Hz
- 数字长码或短码
- 输出格式，默认 MP3，可选 WAV
- 输出目录
- 自定义文本（选择自定义文本类型时启用）

界面显示生成内容预览、预计时长、进度和状态。生成期间禁用生成按钮，成功后可以打开输出文件夹。程序记住上次设置，配置仅保存在本机的 `%APPDATA%\MorseGenerator\settings.json`。

## 摩斯与音频规则

国际摩斯码支持 A-Z、0-9、常用标点及通联符号。速度按 PARIS 标准计算：一个点长为 `1.2 / WPM` 秒，划为三个点，符号间隔一个点，字符间隔三个点，单词或组间隔七个点。

音频为 44.1 kHz、16 位、单声道正弦波。每段音调加入很短的淡入淡出包络，防止点划边缘产生爆音。音频生成和 LRC 使用同一个时间轴，避免同步漂移。

生成时长用于随机内容模式：逐组生成内容，直到加入当前完整组后的预计时长首次达到或超过目标；因此最终音频最多比目标多一个完整组，不截断点划或字符。自定义文本模式以完整输入为准，生成时长字段不参与裁剪。

## 输出

WAV 使用 Python 标准库 `wave` 写入。MP3 使用 `lameenc` 直接编码 PCM，不依赖 FFmpeg。当前 `lameenc` 提供 Python 3.13 Windows 二进制包，运行和打包后均不需要网络。

每次生成音频以及同名 `.lrc` 文件。文件名包含内容类型、WPM、频率和时间戳；若仍发生重名，则自动追加序号，不覆盖已有文件。LRC 包含标题、制作者、速度和逐字符组时间标签，并显示原文与对应摩斯码。

## 代码结构

- `morse_app/core.py`：摩斯转换、时间轴和 PCM 样本生成，不依赖界面。
- `morse_app/content.py`：随机内容、Q 简语及中外呼号生成。
- `morse_app/exporters.py`：WAV、MP3、LRC 写入和安全文件命名。
- `morse_app/settings.py`：本地 JSON 配置的加载、校验和保存。
- `morse_app/gui.py`：Tkinter 界面、后台生成任务和错误提示。
- `main.py`：程序入口。

核心模块仅使用标准库；只有 MP3 导出模块依赖 `lameenc`。GUI 通过后台线程生成文件，避免窗口卡死；线程只返回结果，所有界面更新均由 Tkinter 主线程完成。

## 错误处理

输入为空、数值越界、目录不可写或编码失败时，不产生半成品最终文件，并向用户显示明确的中文错误。输出先写临时文件，完成后再改名为最终文件；如 MP3 编码失败，保留已成功生成的 WAV 临时源并提示其位置，避免用户完全丢失结果。

若未安装 `lameenc` 且用户选择 MP3，程序提示安装方法，但 WAV 功能仍可使用。程序不下载依赖，也不自动联网。

## 测试与验收

自动测试覆盖：

- 字母、数字长短码、标点和通联符号转换
- PARIS 时间规则与组间隔
- 随机内容和呼号格式
- PCM 的采样率、长度、峰值及淡入淡出
- WAV 文件头与音频时长
- MP3 编码的基本可播放文件特征（安装 `lameenc` 时）
- LRC 时间戳与音频时间轴一致
- 参数校验、配置损坏回退和不覆盖已有文件

人工验收包括启动 GUI、逐项切换内容类型、生成 WAV/MP3、播放试听、检查 LRC、确认窗口生成期间不卡死，以及在断网状态下完成全部操作。

## 交付物

交付完整 Python 源码、自动测试、`requirements.txt`、中文使用说明和 PyInstaller 打包脚本。首版目标是正确、简单、离线和易维护，不加入播放器、波形编辑器、皮肤或在线更新。
