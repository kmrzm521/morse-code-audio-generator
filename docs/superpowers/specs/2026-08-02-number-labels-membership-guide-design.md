# 数字编码名称与永久会员获取说明设计

## 目标

在不改变音频编码规则和离线授权机制的前提下，统一数字编码名称，并让用户能够清楚了解永久会员的申请流程。

## 界面调整

- “普通数字”改为“长码”。
- “缩短数字”改为“短码”。
- 内部值继续使用 `long` 和 `short`，保证音频生成逻辑不变。
- 读取旧设置时继续兼容“普通数字”和“缩短数字”，保存新设置时使用新的显示名称。

“永久会员激活”窗口增加以下说明：

1. 在 GitHub 赞助本项目。
2. 将 GitHub 用户名和本机机器码发送到 `kmrzm520@gmail.com`。
3. 赞助记录核实后，永久激活码将通过邮件回复。

窗口保留“复制机器码”和“立即激活”，并增加“复制邮箱地址”和“打开项目主页”。项目主页固定为 `https://github.com/kmrzm521/morse-code-audio-generator`。在 GitHub Sponsors 尚未开通时不放置失效的赞助直达链接；开通后可将按钮目标改为 `https://github.com/sponsors/kmrzm521`。

## 离线与安全边界

- 主程序不调用 GitHub 接口，不自动核对付款，也不发送邮件。
- 只有用户主动点击“打开项目主页”时才调用系统默认浏览器。
- 激活码仍由所有者本地工具离线签发，所有者私钥不进入主程序和公开仓库。
- 所有者必须在 GitHub Sponsors 后台核对用户名与赞助记录，不以截图作为唯一凭证。
